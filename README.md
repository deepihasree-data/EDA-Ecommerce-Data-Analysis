# Ecommerce Sales - Exploratory Data Analysis

## Task 5: Exploratory Data Analysis

### Objective

To explore ecommerce sales data using statistical analysis and visualization to identify patterns, trends, relationships, and potential anomalies.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed

- Dataset overview
- Descriptive statistics
- Missing-value analysis
- Duplicate analysis
- Value-count analysis
- Price distribution
- Quantity distribution
- Boxplots
- Scatterplots
- Category analysis
- City analysis
- Monthly sales trends
- Correlation heatmap
- Pairplot
- Product analysis
- Customer analysis

## Deliverables

- Ecommerce_EDA.ipynb
- Ecommerce_EDA_Report.pdf

## Conclusion

The analysis identified patterns, trends, relationships, and potential anomalies in ecommerce sales data and demonstrated the use of Python-based exploratory data analysis techniques.
